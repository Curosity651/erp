# 海外仓平台服务商结算统一设计

## 一、目标

将海外仓平台现有的“服务商资金”和“应收账单”合并为一个二级菜单“服务商结算”。统一页面同时展示服务商预存资金、逐笔服务费、充值审核和月度对账单，消除“实时扣费后月底再次付款”的歧义。

系统继续定位为业务记录和对账工具，不接入真实支付，不控制银行账户，不进行自动划款。

## 二、统一结算口径

### 2.1 资金余额

每个 WMS 服务商按币种独立维护记录余额：

```text
记录余额 = 审核通过的充值金额 - 已正式入账的平台服务费
```

平台服务费继续来源于 `wms_billing_record` 中 `charge_status = POSTED` 的记录。不同币种不折算、不合并。余额不足只显示预警，不阻断仓库作业。

### 2.2 月度账单

月度账单改为“月度服务对账单”，只汇总该服务商当月已经正式入账的服务费，不产生新的扣款，也不要求针对同一费用再次付款。

月度对账单包含：

- 入库费
- 出库费
- 配送费
- 退货费
- 质检费
- 司机服务费
- 人工补充费用

合同认购款、押金及其他一次性合同资金不进入月度服务对账单。

### 2.3 防止重复结算

生成、复核或查看月度对账单均不得修改服务商资金余额。余额只由两类原始流水决定：

1. 审核通过的充值记录增加余额。
2. 正式入账的平台服务费减少余额。

不得使用 `wms_monthly_bill.total_amount` 再次扣减余额。

## 三、业务流程

### 3.1 充值流程

```text
WMS 服务商登记充值并上传凭证
→ 海外仓平台审核
→ 审核通过后增加记录余额
→ 驳回不计入余额
→ 已通过记录发现错误时通过冲正处理
```

充值状态继续使用：待审核、已通过、已驳回、已取消、已冲正。

### 3.2 服务费流程

```text
仓库业务完成
→ 按有效费率生成逐笔费用
→ 费用正式入账
→ 服务商记录余额实时减少
```

### 3.3 月度对账流程

```text
每月最后一天自动生成当月待复核账单
→ 次月第一天自动复核汇总数据
→ 平台人员查看原始费用明细
→ 点击“复核”
→ 记录复核人和复核时间
→ 对账单锁定
```

复核前发现费用错误时，不直接覆盖自动计费明细，而是在当前账单中登记调整记录：

- `SUPPLEMENT`：补收费，以正数计入服务费和应收金额。
- `DEDUCTION`：冲减费，以负数计入服务费和应收金额。

调整记录必须包含收费项目、正数调整金额、业务凭证和调整原因。系统根据调整类型确定最终正负号，并保留原始费用与调整费用两组明细。调整保存后立即重算待复核账单，也按照正式服务费流水同步影响服务商记录余额。

账单状态简化为：

- `PENDING_REVIEW`：待复核
- `REVIEWED`：已复核
- `DISPUTED`：有异议

兼容现有数据时：

- `DRAFT` 映射为待复核。
- `CONFIRMED` 和 `PAID` 映射为已复核。
- `DISPUTED` 保持有异议。

本轮优先复用现有数据库状态值，前端显示新文案，避免无必要的数据迁移风险。后端复核动作继续使用状态条件更新，防止多人重复复核。

## 四、统一页面

海外仓平台只保留一个二级菜单：`平台财务 → 服务商结算`。

页面由三个紧密关联的区域组成。

### 4.1 资金账户概览

按 WMS 服务商和币种显示：

- WMS 服务商
- 币种
- 累计充值
- 累计服务费
- 当前余额
- 待审核充值数量
- 最近变动时间

余额为负时使用明确警示颜色，但不阻止其他操作。

### 4.2 充值与资金流水

点击服务商账户后打开详情抽屉，保留两个选项卡：

- 充值审核：查看凭证、通过、驳回、冲正。
- 资金流水：按时间展示充值、冲正和逐笔服务费。

### 4.3 月度服务对账单

统一页面下方展示月度账单列表：

- 账期
- WMS 服务商
- 各费用类型小计
- 合计金额
- 状态
- 复核人
- 复核时间
- 操作

待复核账单右侧显示“复核”按钮。点击后先打开账单详情，展示全部原始收费记录和分类汇总，再由操作员确认复核。

“登记补充费用”不再作为页面级按钮，改为每条未复核或有异议账单的“调整费用”操作。复核弹窗同时展示原始金额、补收/冲减明细、调整净额和最终应收金额。

已复核账单只允许查看，不允许重新计算、补录费用或再次复核。

有异议账单允许处理完差异后重新进入复核流程。

## 五、按钮与菜单调整

删除普通页面中的：

- “生成账单”按钮
- “标记已付款”按钮
- 月度账单付款凭证上传入口

保留：

- “登记补充费用”，但只能作用于尚未复核的账期。
- 后端人工生成/重算接口，作为异常修复能力，不在普通前端展示。
- 月末自动生成和次月初自动复核汇总任务。

原“应收账单”菜单隐藏或重定向到“服务商结算”，避免出现两个入口。

## 六、权限边界

- 海外仓平台：查看所有服务商账户、审核服务商充值、查看流水、复核月度账单。
- WMS 服务商：登记向平台充值、查看自身余额、充值记录、费用流水和月度对账结果。
- ERP 货主：不能访问平台与 WMS 服务商之间的账户和账单。

所有查询继续按身份和服务商租户隔离。

## 七、异常与审计

- 充值审核、驳回和冲正记录操作人、时间及原因。
- 月度复核记录复核人和复核时间。
- 每笔账单调整记录调整类型、业务凭证、调整原因、操作人和时间。
- 待复核账单可随业务流水重算；已复核账单不可被定时任务覆盖。
- 补充费用必须包含业务凭证和计费说明。
- 对账单复核失败时保持原状态，不产生部分更新。

## 八、实施范围

### 后端

- 调整月度账单状态文案及复核接口语义。
- 保留自动生成与次月初重算。
- 移除普通流程对账单付款动作的使用入口。
- 在账单详情中补充复核人字段和完整费用明细。
- 验证资金余额始终只读取充值记录和逐笔服务费。

### 前端

- 将服务商资金页面扩展为统一“服务商结算”页面。
- 合并月度账单列表和详情抽屉。
- 删除生成账单和标记付款操作。
- 增加逐条复核按钮。
- 隐藏原应收账单菜单并配置旧路由重定向。

### 数据库与迁移

- 调整菜单名称和可见性。
- 如现有账单表缺少复核人字段，则增加复核人 ID 和名称快照。
- 不迁移或重复生成原始费用，不改变历史资金余额。

## 九、验收标准

1. 海外仓平台只通过“服务商结算”访问两类信息。
2. 服务商账户余额等于审核通过充值减去正式服务费。
3. 月末自动生成待复核账单，普通页面没有手动生成按钮。
4. 每张待复核账单可以单独复核并记录操作人和时间。
5. 复核账单不会再次扣减余额。
6. 已复核账单不能被重算或补录费用覆盖。
7. 充值凭证只保存在充值记录中，不要求月度账单重复上传付款凭证。
8. 旧应收账单入口不再单独显示。
