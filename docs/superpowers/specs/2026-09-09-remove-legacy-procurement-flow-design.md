# 删除旧采购物流链路设计

## 目标

从 ERP 货主端移除物流商管理、采购单管理、物流单管理和采购入库单四条业务链路，不再允许用户访问或调用这些专属功能。

## 边界

- 删除四个菜单及按钮权限、前端页面、专属前端 API 和专属后端控制器。
- 删除只服务于采购单、物流单和物流商管理的后端模型、服务、映射器与 XML。
- 采购入库单专属创建、编辑、提交、取消和导出入口删除。
- 保留 `wms_purchase_inbound_order`、`wms_purchase_inbound_order_item` 及其共享模型和服务，因为自定义入库、退货入库、海外仓收货与上架仍依赖它们。
- 保留历史业务表和历史数据，不执行物理删表或清空。
- 解除库存预测、发货生产测算和入库执行对采购单、物流单专属服务的编译依赖；无法继续成立的旧预测数据源从结果中移除。

## 数据库

新增幂等迁移脚本，将四个页面菜单和其后代按钮权限标记删除，并清理角色菜单关系。迁移不删除业务数据表。

## 验证

- 前端类型检查和生产构建通过。
- 后端管理模块编译及相关测试通过。
- 菜单迁移脚本可重复执行。
- 自定义入库、退货入库、海外仓收货和上架的接口与页面仍可编译和访问。
