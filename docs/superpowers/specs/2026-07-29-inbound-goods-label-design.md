# 收货商品贴标设计

## 目标

海外仓完成入库收货后，可以按实收件数打印商品标签，并打印一张带商品图片的货物对照表。货主端继续使用原始 SKU，内部仓库 SKU 仅供海外仓识别和扫码。

## 内部仓库 SKU

- 格式：`货主名称-原始SKU`，例如 `JHIN-ADNZ-015-TXW`，与完整入库单号使用同一货主前缀。
- 不引入批次，也不改变库存底层的 `erpTenantId + skuCode` 归属。
- 内部仓库 SKU 为确定性派生编码，不单独维护可编辑字段。
- 海外仓后端扫码同时接受内部仓库 SKU、原始 SKU 和已维护商品条码。

## 打印入口

海外仓“入库收货”列表中，状态为“已收货”或“已完成”的单据显示：

- `商品标签`：按各 SKU 实收数量一件一张打印；相同 SKU 的多条明细先聚合。
- `货物对照表`：每种 SKU 一行，展示商品主图、内部 SKU、原始 SKU、商品名称和实收数量。

两个操作均为可重复打印的只读操作，不修改收货、库存或上架状态。

## 打印格式

商品标签采用紧凑的 50mm × 25mm 横向版式，每个实收箱子打印一张：

- 上方只显示内部仓库 SKU 对应的 Code 128 一维条形码。
- 条形码下方使用一行小字显示完整内部仓库 SKU。
- 不再显示二维码、货主、原始 SKU、商品名称、入库单号或件数序号。
- 标签内容靠中排列并压缩页边距，不保留无业务意义的空白。
- 内部仓库 SKU 较长时缩小文字，但不得截断编码；条形码必须保持可扫描的静区和高度。

选择 Code 128 是因为内部仓库 SKU 包含字母、数字和连字符，无法统一使用只支持纯数字的 EAN-13。条形码由成熟前端条码库生成，不手写编码算法。

货物对照表继续采用 A4，商品主图缺失或加载失败时显示“暂无图片”。本次修改不改变货物对照表。

## 异常处理

- 入库单没有实收数量时禁止打印标签。
- 任一实收商品缺少内部仓库 SKU 时禁止打印，避免生成无法识别归属的标签。
- 浏览器阻止弹窗、详情加载失败或条形码生成失败时，关闭空白打印窗口并显示明确错误。
